O NOME "SONARE" — 3 TRATAMENTOS

Layout A (o que você aprovou) com o wordmark redesenhado três formas diferentes. Continua sendo texto real (legível, sem risco de virar ilegível), mas cada letra agora tem posição própria — não é mais um ctx.fillText genérico.

Partiturarecomendado

SONARE escrito sobre uma pauta de verdade — 5 linhas finas atravessando o nome, cada letra pousada numa altura diferente, como se fosse a melodia do próprio nome do jogo. É o mais literal com "sentido de nota".

Onda

As letras cavalgam uma onda que viaja pelo nome continuamente, com um traço fino costurando todas elas por baixo — o nome vira literalmente uma onda sonora, e o traço ecoa a mecânica de "uma corrente só" do jogo.

Sequência

Posição normal, bem estável e legível — mas cada letra acende em sequência, da esquerda pra direita, como se o próprio nome fosse tocado feito um carrilhão. O mais discreto dos três.

Todas em canvas ao vivo. As letras são desenhadas uma a uma (não é mais uma chamada só de texto) — o que abre caminho pra, no futuro, trocar por um logotipo 100% vetorial se topar ir mais longe ainda.
